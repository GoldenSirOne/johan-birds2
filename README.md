# Fågelstigen

En responsiv svensk fågelguide med interaktiva fågelkort, sökning, kategorifilter och en personlig guide.

## Innehåll
- Nio svenska fågelprofiler med kännetecken, föda, livsmiljö och kuriosa.
- Sökning och filter för trädgård, skog, vatten och rovfåglar.
- Detaljkort med guidens pratbubblor.
- Cykel- och naturinspirerad design för mobil och dator.

## GitHub Pages
Öppna repositoryts **Settings → Pages** och välj **Deploy from a branch**, branch `main` och folder `/(root)`. Sajten publiceras därefter på GitHub Pages.
